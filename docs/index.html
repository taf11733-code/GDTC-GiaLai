⚙️ Cài đặt WebApp Google Apps Script

Cổng GitHub Pages này giúp giáo viên và các đơn vị truy cập vào WebApp Google Apps Script với tên miền tiện lợi, ổn định:

  1. Vào dự án Google Apps Script của bạn.
  2. Bấm Deploy (Triển khai) → New deployment (hoặc Manage deployments).
  3. Sao chép đường dẫn Web app URL kết thúc bằng /exec.
  4. Dán vào ô bên dưới rồi nhấn Lưu & Khởi chạy.

💡 Mẹo: Bạn cũng có thể gửi link trực tiếp kèm tham số: ?url=https://script.google.com/.../exec để tự động kết nối mà không cần cài đặt lại!
